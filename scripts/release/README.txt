FIRST Robotics Inventory - 使用说明
====================================

一、安装（目标电脑无需安装 Go / Node.js）
  1. 把整个文件夹解压到任意位置（建议 D:\FIRST-Robot-Inventory）
  2. 双击 start.bat 启动
  3. 首次启动 Windows 防火墙会弹窗询问，请勾选「专用网络」并点「允许访问」
     （勾选后同一局域网的其他电脑才能打开本系统）

二、日常使用
  1. 双击 start.bat（或桌面快捷方式 FIRST-Inventory）
  2. 浏览器会自动打开出入库页面：
        http://127.0.0.1:8000/#/checkout   （出入库/扫码）
        http://127.0.0.1:8000/#/board      （展板/库存预警）
  3. 关闭弹出的黑色窗口 = 停止服务

三、局域网共用（一台电脑当服务器，多台电脑一起用）
  - 服务会监听本机所有网卡，启动窗口里会打印一行：
        On this network: http://192.168.x.x:8000/#/checkout
    其他电脑用浏览器打开这个地址即可，不需要安装任何东西。
  - 看不到地址时，在服务器上运行 ipconfig 查看 IPv4 地址，端口固定为 8000。
  - 连不上时依次检查：
      1) 服务器窗口是否还开着（关掉窗口服务就停了）
      2) 防火墙是否已放行（见上面第一步第 3 点）
      3) 两台电脑是否在同一个局域网 / 同一个 Wi-Fi
  - 注意：本系统没有登录功能，凡是能访问到这个地址的人都能修改库存，
    请只在可信的仓库内网中使用，不要暴露到公网。

四、数据存放
  - 数据库在 data\inventory.db，保留 data 文件夹即可，升级版本不丢数据
  - 重要数据请在「设置」页点击「备份数据库」，备份在 data\backups\
  - 如需在另一台电脑使用相同数据：把整个 data 文件夹复制过去覆盖

五、常见问题
  - 端口 8000 被占用：关闭占用 8000 的程序后重试
  - start.bat 一闪而过：右键「以管理员身份运行」试一次
  - 杀毒软件误报：首次运行如被拦截，请选择允许
    （本程序是单文件绿色程序，不会主动向外网发送任何数据）
